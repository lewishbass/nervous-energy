[H-Scores](https://arxiv.org/pdf/2212.10082v1)

$ H(f) = \text{tr}(\text{cov}(f(X))^-1 \cdot \text{cov}(E[f(X) | Y])) $


| variable | description |
|----------|-------------|
|$X$ | input vector |
|$Y$ | label |
|$f(X)$ | feature vector |
|$\text{cov}(f(X))$ | covariance matrix of the feature vector (feature redundancy) |
|$\text{cov}(E[f(X) \mid Y])$ | covariance matrix of the conditional expectation (feature relevance) |
